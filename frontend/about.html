What it does

Two modes. One pipeline.

{ }

Code Mode

Paste code in Python, Java, C, or C++

The system explains what the code does, analyzes its worst-case time and space complexity, and checks whether it is correct and optimal.

If it is buggy or slow, it doesn't just tell you — it finds the root cause, recommends a better data structure and strategy, and shows a brute-force and an optimal rewrite side by side.

?

Problem Mode

Describe a problem in plain English

Pick a language (or let the system use the one you mention) and get a brute-force solution, an optimal solution, a step-by-step dry run, edge cases, and a final complexity summary.

If the simple approach is already optimal — like a tree traversal — the system says so instead of inventing a "better" one.

Agent design

Specialized agents, not one giant prompt.

Each agent has one narrow job: classify, explain, measure, judge, diagnose, recommend, generate, or summarize. Narrow prompts produce more reliable answers than a single do-everything prompt.

🔗

Grounded in earlier results

Later agents receive what earlier ones produced — the dry run traces the exact optimal code shown, and the summary copies complexities from the real solutions.

🧾

Structured decisions

Classification, code review, and strategy choices come back as JSON, so the pipeline branches on clear yes/no answers instead of guessing from free text.

⚡

Parallel stages

Agents that don't depend on each other run at the same time, so a full analysis finishes faster than running them one by one.

Research abstract

The problem this solves

The growing use of artificial intelligence in software development, competitive programming, and technical interview preparation has created new opportunities for intelligent code assistance. Most existing tools, however, focus on code execution or generation alone — without structured feedback, step-by-step reasoning, or optimization guidance grounded in data structures and algorithms.

This project introduces AlgoMentor, an AI-enhanced algorithmic code tutor: a multi-language, orchestration-based system designed to analyze user-written code, interpret problem statements, suggest algorithmic improvements, and teach optimal solutions through detailed explanation.

The system supports both Code Mode and Problem Mode across Python, Java, C, and C++. It runs a pipeline of specialized LLM agents covering input classification and language detection, explanation, complexity analysis, correctness and optimality review, root-cause diagnosis, data structure and strategy recommendation, solution generation, dry-run explanation, and summarization. Each agent builds on the outputs of earlier agents, which keeps explanations, dry runs, and complexity claims consistent with the code actually shown.

By combining LLM reasoning with DSA knowledge, the tool works at once as an intelligent tutor, an interview preparation assistant, and an algorithm explainer.
